# 🌐 Site Seven - Empresa Desenvolvedora do HelpHouse

Este repositório contém o site da **Seven**, empresa responsável pelo desenvolvimento dos aplicativos **HelpHouse**. O site apresenta informações sobre a empresa, projetos desenvolvidos pela equipe, detalhes sobre os desenvolvedores e um formulário de contato.

## 🚀 Tecnologias Utilizadas

- **HTML5** - Estrutura e conteúdo da página
- **CSS3** - Estilos e layout do site
- **JavaScript** - Funcionalidades dinâmicas, como interações no formulário de contato

## 🛠️ Funcionalidades

- **Página inicial:** com informações sobre a Seven e seus serviços
- **Projetos:** exibindo as principais criações da equipe
- **Desenvolvedores:** com links de contato para cada membro da equipe
- **Formulário de contato:** permitindo que os visitantes entrem em contato diretamente com a empresa
